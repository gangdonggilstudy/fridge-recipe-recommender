## 이 앱을 한 문단으로

냉장고 재료를 입력하면 **개인 취향·유통기한·시간·날씨**를 종합해 요리를 추천하는 Streamlit 웹앱. 처음엔 모두에게 같은 **규칙(룰)** 으로 추천하고, 사용자의 선택 기록이 50건 쌓이면 그 사람만의 **개인 AI(로지스틱 회귀)** 를 자동 학습해 점점 개인화됩니다. 모든 외부 의존성(LLM·날씨·음성)은 **fallback**이 있어 키 없이도 완전히 동작합니다. → [상세](01_overview.md)

## 5초 구조 요약

```
사용자 → ui/ → app_services(조립공장) → Recommender → Scorer ┬ 룰 레짐
                                              │              └ ML 블렌더
                                              └ *_repo → app.db / recipes.db / models/
```

| 계층 | 폴더 | 대표 |
|---|---|---|
| 화면 | `ui/` | result, fridge, onboarding |
| 조립 | `app_services.py` | `get_*()` 싱글톤 |
| 두뇌 | `modules/` | Recommender, Scorer, MLModel |
| AI텍스트 | `llm/` | Narrator (+fallback) |
| 데이터 | `*_repo.py` | BaseRepository 상속 |

→ [아키텍처 상세](02_architecture.md)

## 추천 점수 = 5요소

| 요소 | 가중치 | 무엇 |
|---|---|---|
| 재료 일치도 | **0.35** | 레시피 재료 보유율 (+카테고리 부분점수) |
| 소모 우선순위 | 0.25 | 유통기한 임박 재료 활용도 |
| 선호도 | 0.20 | 내 취향 벡터와 코사인 유사도 |
| 상황 적합도 | 0.15 | 시간(0.55)·날씨(0.29)·월(0.16) |
| 다양성 | 0.05 | 한 스타일 쏠림 방지 |

**합치는 두 방법:**
- **룰**: `Σ(가중치 × 요소)` — 신규 사용자
- **블렌더**: `σ(절편 + Σ 학습가중치×피처)` — 학습된 사용자

→ [숫자 예제로 끝까지](04_recommendation_logic.md)

## 추천 흐름 6단계

```
① 후보 필터 (재료 매칭 − 알레르기 하드필터)
② 콜드스타트 판정 (개인벡터 → 인구통계 그룹 → 룰)
③ 5요소 점수 (룰 or ML 자동 선택)
④ 1차 정렬 → 다양성 보너스 → 2차 정렬
⑤ 상위 N개 반환
⑥ 선택/거부 → 선호 갱신 + 학습 트리거
```

## 머신러닝 핵심

| 항목 | 값 |
|---|---|
| 모델 | 로지스틱 회귀 (사용자별 독립) |
| 피처 | 5개 (4점수 + 시기 적합) |
| 활성화 | 기록 **50건** 이상 |
| 재학습 | 마지막 학습 후 **+25건** |
| 최신성 가중 | **0.95** (선호 벡터와 공유) |
| 특별함 | **설명 가능** — 기여도를 정확히 분해 (충실성 불변식) |
| 철학 | ML 실패해도 **룰로 폴백, 앱은 안 죽음** |

→ [ML 쉽게 풀어쓰기](06_ml_explained.md)

## 이 코드의 6가지 영리한 결정

1. **룰 ↔ ML 매끄러운 전환** — 같은 5요소 위에서 데이터 쌓이면 자동 승급, 끊김 없음
2. **설명 가능한 ML** — 블랙박스가 아니라 기여도 분해 (왜 이 추천?)
3. **콜드스타트 3단 폴백** — 개인벡터 → 인구통계 그룹평균 → 룰
4. **비대칭 피드백** — 선택 +1.0 > 거부 −0.5 (초기 신호 노이즈 완화)
5. **다양성 2-pass** — 상위권 우위 유지하며 쏠림 방지
6. **단일 출처 원칙** — 시기 적합(temporal_fit) 계산 등을 한 함수로 → train/predict 스큐 차단
7. **약한 미선택 신호** — 별로에요 없이 선택만 하면 ML이 "아니오"를 못 배움 → 노출됐는데 안 고른 추천을 신뢰도 0.2의 약한 음성으로 활용 ([06](06_ml_explained.md))
